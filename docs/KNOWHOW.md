# KNOWHOW

**このリポジトリ固有の、つまずき・事故・調査知見の記録。**
CLAUDE.mdを短く保つため、詳細はここに積み、CLAUDE.mdからは短く参照する。
他repoにもそのまま効く一般則になったら `uball/cost` のplaybookへ昇格する。

書き方の決まり:

- **番号を振って追記する**(消さない。訂正するときは元を残して「訂正」と書く)。
- 1件につき **何が起きたか / なぜそうなったか / どう直したか / 次はどう避けるか** の4点。
- **数字は測った日付とセットで書く。** 日付の無い数字は、後から現状だと誤解される。
- **測り方(コマンド・クエリ)も一緒に残す。** 結論だけだと再現できず、
  数か月後に同じ調査を1からやり直すことになる。
